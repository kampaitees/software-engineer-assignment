# Trao submission checklist

1. Push repository to GitHub with meaningful commits.
2. Deploy frontend and backend publicly.
3. Configure MongoDB and Gemini credentials on the deployment platforms.
4. Verify `GET /health` and frontend login/create-kit flow.
5. Run the mandatory evaluator from a clean clone.
6. Record a 3–4 minute walkthrough covering: end-to-end generation, research sequence, second-pass gap closure, editing/reordering, regeneration preserving edits, practice mode, schedule and one design decision.
7. Submit GitHub URL, deployment URL and README through the Trao careers page.
